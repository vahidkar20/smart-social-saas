# Smart Social SaaS (Refactored)

A complete SaaS platform for Social Media Automation, AI Content Generation, and Bot Building in WordPress.

## Setup & Usage (راهنمای استفاده)

This plugin is designed as a full application within your WordPress dashboard.

**1. WordPress Dashboard Access (Primary Method):**
Once installed and activated, look for the new menu item named **"اتوماسیون من"** (My Automation) in your WordPress Admin sidebar. Clicking this will open the full, unified application dashboard. You do **not** need to place a shortcode on any page to use the application yourself.

**2. Frontend Access (Optional):**
If you wish to expose the dashboard on the frontend of your website (e.g., for users or team members without giving them WP Admin access), you can create a new Page in WordPress and use the following shortcode:

```text
[ssp_portal]
```

## First Steps
When you open the portal for the first time, an interactive **Quick Start Guide** (Onboarding) will help you:
1. Connect your Telegram/Social profiles.
2. Setup your AI capabilities (either via standard API Keys or via the free Browser Bridge).

Enjoy your automated workflows!
